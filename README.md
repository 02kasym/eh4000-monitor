# Монитор EH4000AC-3 — цифровая панель

Веб-копия бортового монитора самосвала с кнопочной панелью (?, стрелки, ✱, ✕, ○).
Чистый HTML/CSS/JS, без сборки — подходит для GitHub Pages.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите **содержимое папки `site`** в корень репозитория.
2. Settings → Pages → Source: *Deploy from a branch*, Branch: `main`, папка `/ (root)` → Save.
3. Через 1–2 минуты сайт будет доступен по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.

> Открывать `index.html` двойным кликом нельзя — браузер не загрузит JS-модули с диска.
> Локально: `python3 -m http.server` в папке `site`, затем http://localhost:8000

## Кнопки

| Кнопка | Клавиатура | Назначение |
|---|---|---|
| ↑ ↓ | стрелки | Выбрать пункт / страница (Стр.) |
| ← → | стрелки | Вкладка (Класс), Ав. сигн./Неисправн., перемотка |
| ○ | Enter, пробел | устан. / Меню / Пуск записи / Удерж. |
| ✕ | Esc, Backspace | Назад / Отмена |
| ? | H | Сброс мин./макс. на страницах; на главном — цифровые значения |
| ✱ | B | Яркость экрана (3 уровня) |

## Структура

- `js/data/` — содержимое экранов (вкладки «Двигат.», «Гидравл.», «Привод перем.тока»), перенесено с фото
- `js/screens/` — отрисовка экранов
- `js/app.js` — навигация и состояние
- `css/` — стили корпуса и экранов

Разделы «Журнал технического обслуживания», «Данные машины», «Различные настройки» на фото не попали — там стоят заглушки.
